# 双向增量和账号配置恢复候选

截至2026-10-24，代码位于 `android/client` 和 `server/v3`，服务端已部署，Android 1.14.20/121已发布；119快照保留。

## 传输与确认

上传沿用备份条目增量。下载新增MSD1协议：8字节magic、4字节大端JSON头长度、描述基线复制段与字面量段的JSON头、字面量内容。基线和结果都校验完整SHA-256，重建使用临时文件且不覆盖已有目标；无收益或旧端点则走完整下载。缓存是派生文件，访问缓存仍验证两端摘要属于当前账号。预算按实际差量大小保守预留，Range支持续传。

聊天继续使用显式应用ACK。新的profile ACK仅作为配置三方合并基线，不更新聊天删除证明，也不允许配置省略项触发删除。新增表向后兼容；清理将其摘要作为存活引用。

## 恢复和现有数据

原始原生导出保留为本机安全备份；另建可移植同步投影。同步导出不带API Key，因此投影从本机原生仓库读取通用API Key，按原生备份编码写入私有账号包。APK和仓库不保存私人密钥。设备OAuth、桥接令牌及回环供应商不复制。

导入只调用供应商分类导入，不调用全量还原。原有供应商值和密钥保留；技能内容先校验摘要和大小，再无覆盖发布，冲突保存恢复件。配置应用结果实际匹配云端内容时才发profile ACK。发生本机修改、损坏内容或串号时停止并保留恢复入口。

首次登录可触发恢复，无需充电；后续后台仍由既有系统条件调度，尚非实时共享。首次恢复不触发NAS联动。安装绑定首个账号和服务端用户ID，拒绝其他账号；完整多账号工作区、退出清理、设备授权和端到端加密待完成。
